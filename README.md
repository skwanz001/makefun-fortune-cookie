## The fortune

> The bug you cannot reproduce will reproduce the moment your manager looks over your shoulder.

93 characters, one line. The joke is the observer effect every engineer knows:
the unreproducible bug only shows up the second someone senior is watching.

## How it works

`main.py` (Python 3.13 standard library only) writes that single line to
`/output/entry.txt`, after self-checking it against the gate: UTF-8 text,
1–120 characters, one line, not only whitespace.

```sh
python3 main.py
```
